# App-Iglesia
Aplicación web de Biblia e himnario.

Biblia
Edición Reina-Valera 1960
bible/index.html

Himnario
Coros e himnos de la iglesia evangélica.
hymnal/index.html

Administrador de Himnario
Permite agregar y editar Alabanzas, estas se guardan como archivo .js.
Permite trabajar con IA Gemini para completar letras de Alabanzas. Colocar API Key en `/admin-songs/js/config.js`.
Archivo resultante guardar en `/hymnal/data/data.hymnal.js`.
